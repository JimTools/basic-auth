# Overview

## Installation

The recommended way to install this package is with Composer. Composer is a dependency management tool for PHP that
allows you to declare the dependencies your project needs and installs them into your project

```bash
composer require jimtools/basic-auth
composer remove tuupola/slim-basic-auth # migration only
```
